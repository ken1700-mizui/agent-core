>
> - **今回は、監査そのものは行っていない。** この文書は、Phase 0.5 で行う監査の準備である。
> - **監査の対象のコミット：** 最終修正のコミットが確定した後、監査を始めるときに、外部の指示で SHA を1つに固定する（`対象の SHA：________`）。固定した後の変更は、監査の対象に含めない。
> - **この監査は、設計の監査である。** 実装や動作の検証の結果ではない。どちらの合格も、実装した後に別に行う試験を置き換えない。
> - 初回 Phase 0 報告書の全文は、Claude Code の側では受け取っていない。全文との照合は、この監査の範囲の外（A-P6）。

## 1. 指摘の重大度

| 重大度 | 意味 | Phase 1 の開始への影響 |
|---|---|---|
| 重大 | 安全、データの消失、費用の制御を、根本から損なう。不変条件どうしが矛盾している | 解決するまで始めない |
| 高 | 誤りが起きる可能性の高い、設計の欠陥。重要な状態遷移が定まっていない | 解決するか、オーナーが受け入れるまで始めない |
| 中 | 曖昧さ、資料の間の食い違い。Phase 1 の範囲の外の欠陥 | 該当する Phase の前に解決する |
| 低 | 表現、構成、記載の漏れ | 任意 |
