## 4. 保証の範囲

- Safety Gate の3つの条件（外部への通信 0 件、Permit のない副作用 0 件、認証情報が存在しないこと）は、次の範囲で確かめた。
  - import の契約
  - 試験の中の通信の遮断（Python の `socket` の経路）
  - Permit の試験
  - 秘密情報の検査
  - 合成のデータ専用の条件（P-6）
- **主張しないこと：**
  - 包括的なセキュリティ監査の完了（5章のとおり後で行う）。
  - OS のレベルの完全な隔離。
  - 同じ利用者の協調しないプロセス、root、DB を持つ者の一貫した書き換えの検出。
  - 物理的な容量の厳密な上限の保証。
  - 起動の時間の制限の永続的な保証。
