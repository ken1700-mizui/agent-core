### 5.6 読み方：偏りと有限回の誤差

**元の手法には、偏りがあった。**
- 同じデータで比べると、元の区間だけが真の値を含んだ回は 1〜6 回だった。新しい区間だけが含んだ回は 20〜32 回だった。
- 元の手法の被覆率（0.935〜0.948）は、解析的な予測（0.940）のとおりに低かった。

**新しい手法では、偏りは見られない。**
- 分散の比は 0.95〜1.05 だった。
- 偏差は、ほとんどが ±1.5 の内にある。2 を超えたものは次の3つ。

  | 項目 | 偏差 | 範囲の内か |
  |---|---|---|
  | at_delta_imp の被覆率 | +2.36 | 内 |
  | few_clusters の被覆率 | +2.36 | 内 |
  | rule_a_assumed の検出力 | −2.07 | 内（計画との差 −0.015） |

- 少ないクラスタの並べ替えは離散的なので、区間がやや保守的になることは予想の範囲である。
- 計画の検出力は正規近似なので、手順の全体では、わずかに楽観的になりうる。

**元の at_delta_imp の不合格（0.0365）について：** 新しい手法では、同じデータで 0.0260、新しい種で 0.0220、元の種で 0.0285 になった。

### 5.7 わかったこと（基準とは別に報告する）

- **成功率の非劣性が、段階1を決めている。**
  - 効果なしの手順の全体では、83〜85% の回が段階1で止まった。
  - 原因は、40 クラスタ × 4 タスク × 3 回のとき、成功率の SE が約 3 ポイントで、δ_ni = 3 ポイントと同じ程度になることである。
  - D 8.5 のとおり、正式な実験の前に、手順の全体の検出力で標本の大きさを決める必要がある。
- **rule_b_holm_null は弱い確認にとどまる。** 採用の率が 0.0065 と低いのは、段階1が多くの回を止めるためである。そのため、この状況は Holm の水準を弱くしか確かめていない。Holm の水準そのものは、単体の試験（片側 0.0125 で先に通る必要）で確かめた。
- **分散が 0 の場合のオーナーの判断が要る。** 安全側として、分散が 0 の場合は何も決めない。両方とも全部 0 の維持すべき指標（例：人間の介入）を NI_MET と扱うかは、オーナーの判断を求める。
