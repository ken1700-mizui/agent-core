## 設計E でロードマップに反映する、オーナーの最新の方針（2026-11-26）

Agent Core は商用の製品ではなく、**まずオーナー自身が使うための、専用の AI の基盤**である。

1. 最も優先するのは、AI の性能、品質、自律性、費用の効率、安定性。
2. 商用化、課金の仕組み、一般への公開、多数の利用者への対応は、必須の目標ではない。
3. マルチテナントの将来の拡張性は保つ。ただし、初期の実装を必要以上に複雑にしない。
4. スマートフォンからの遠隔操作と、長時間の稼働を重視する。
5. 最後に、Service Harness を、独立したサブ機能として加える。
6. LINE、X、YouTube、Instagram、Facebook などの公式の API を使う、サービスごとの Harness を、将来開発する。
7. Service Harness の実装は、Agent Core の本体の完成の条件に含めない。

- 今回は、Service Harness の詳しい設計も実装も行っていない。
- この方針により、C1・C2・D で「マルチテナント化の前に必要」とした機能の優先度は、E で見直す（必須の安全機能は除く）。
