# ADR-0007：文書の言語の方針

- **状態：** **ACCEPTED**（オーナー確定事項 D4）
- **日付：** 2026-11-26

> 出典：独立審査者が確かめた、初回 Phase 0 報告書の予定（7件の ADR）。初回報告書の全文は、Claude Code の側では受け取っていない（A-P6 は未完了）。

## 決定

- 人間向けの文書は日本語で書く。
- AI 向けの文書（`AGENTS.md`、`CLAUDE.md`、プロンプト）は英語で書く。
- 識別子は、英語のままにする。

## 理由

- オーナーが読みやすく、エージェントが正確に解釈できるようにする。
