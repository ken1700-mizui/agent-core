# ADR-0004：コードで強制する Safety と Sandbox

- **状態：** PROPOSED
- **日付：** 2026-11-26

> 出典：独立審査者が確かめた、初回 Phase 0 報告書の予定（7件の ADR）。初回報告書の全文は、Claude Code の側では受け取っていない（A-P6 は未完了）。

## 決定

- 安全は、モデルへの指示ではなく、コードと OS で強制する。
  - PDP と PEP、Permit、送信の関門
  - Sandbox（Docker）、Egress Gateway
  - SAG、予算の強制
- AI による判定は、制限を加える方向にだけ使う。

## 理由

- モデルは、外部の指示に騙されうる。

## 影響と、注意すること

- Docker だけで安全とはみなさない。OS のレベルの強制は、Phase 3A で確かめる。
