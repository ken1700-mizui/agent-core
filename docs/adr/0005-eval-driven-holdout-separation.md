# ADR-0005：評価駆動の開発と、holdout の分離

- **状態：** holdout の分離は **ACCEPTED**（オーナー確定事項 D3）。それ以外は **PROPOSED**
- **日付：** 2026-11-26

> 出典：独立審査者が確かめた、初回 Phase 0 報告書の予定（7件の ADR）。初回報告書の全文は、Claude Code の側では受け取っていない（A-P6 は未完了）。

## 決定

- 性能の主張は、事前登録した評価の結果にだけ基づける。
- holdout は、独立した非公開のリポジトリに置き、開発の側の AI には接続しない。

## 理由

- 評価の汚染を防ぎ、改善が本物かどうかを確かめるため。

## 影響と、注意すること

- 採点のプログラムと holdout を、無断で変えてはならない（AGENTS.md）。
